## Всем привет 👋

# 1С-разработчик

Разрабатываю информационные базы для малого бизнеса на платформе 1С:Предприятие. 
Специализируюсь на проектировании метаданных, адаптации под БСП и доработке 
прикладных решений под задачи конкретного бизнеса.

## Направление работы

- Разработка информационных баз «с нуля» и на базе БСП
- Проектирование метаданных: справочники, документы, регистры, перечисления, отчёты, обработки
- Настройка прав доступа и ролей
- Внедрение БСП в существующие решения и адаптация базы под библиотеку
- Работа с расширениями конфигурации
- Оформление фирменного стиля интерфейса

## Проекты

### ИБ для барбер-шопа
Информационная база для учёта работы барбер-шопа. Изначально разработана 
без БСП, позже выполнено внедрение БСП и адаптация базы под библиотеку.
Реализованы справочники, документы, регистры, отчёты и обработки, настроены 
права доступа, оформлен фирменный стиль.

### ИБ для груминг-салона
Информационная база для груминг-салона. Разработана без БСП, затем выполнено 
внедрение БСП с адаптацией существующей структуры. Реализованы необходимые 
метаданные, права доступа, отчётность и обработки, оформлен фирменный стиль.

### ИБ для салона красоты
Информационная база для салона красоты, изначально спроектированная на базе БСП. 
Реализованы справочники, документы, регистры, отчёты и обработки, настроены 
права доступа, оформлен фирменный стиль.
